# 恢復本聖經查詢系統 RcV Bible Search

**線上使用：** https://idmsjt.github.io/RcV-bible-searching/

一個離線可用的恢復本聖經雙語（中英文）查詢工具，無需安裝，直接用瀏覽器開啟即可。

---

## 功能介紹

### 📖 三種查詢模式

| 模式 | 說明 |
|------|------|
| **經節查詢** | 輸入經節引用，支援中英文混合輸入 |
| **全文搜尋** | 中英文關鍵字搜尋全部 31,206 節 |
| **瀏覽** | 按書卷、章節逐節閱讀 |

### 🔤 支援的中文輸入格式

```
約一1              # 縮寫 + 中文章 + 阿拉伯節
約1:1              # 縮寫 + 阿拉伯章:節
約翰一章一節        # 部分書名 + 中文章節
約翰福音一章一節    # 全名 + 中文章節
啓一2              # 啓（異體字）也支援
啟一4-5            # 節範圍（橫線）
啟二一9～10        # 節範圍（全形波浪）
4:5, 5:6           # 同書換章（在書名之後）
十四節             # 同章換節（純中文節數）
```

**大量輸入範例：**
```
啟一4-5，4:5，亞十二2，3:4，約翰一章一節，十四節，馬太福音二十六章四節，十六節，二四章一節，11
約一2，十四7~8、23, 約翰三34，約壹二27，三9，啟二一9～10, 二二章13節，創一2
```

### 🔤 支援的英文輸入格式

```
Gen. 1:1, 3, 3:5   # 縮寫 + 逗號連續節 + 換章
Genesis 1:1-3       # 全名 + 節範圍
John 1:1, 14        # 逗號跳節
Rev 22:13           # 縮寫
1 John 1:1-3        # 含數字書名
```

### 📋 複製格式

| 按鈕 | 輸出格式 |
|------|---------|
| 複製中文 | `約一1『太初有話，話與神同在，話就是神。』` |
| Copy EN | `John 1:1 "In the beginning was the Word..."` |
| 雙語 | 中文一行 + 英文一行，交錯輸出 |

### 🌐 三欄佈局

- **左欄**：書卷目錄（舊約／新約，可獨立捲動）
- **中欄**：查詢結果（可獨立捲動）
- **右欄**：點選經節後，顯示該章全文（可獨立捲動）

## 使用方式

### 方法一：線上使用（推薦，手機也可用）
直接開啟：**https://idmsjt.github.io/RcV-bible-searching/**

### 方法二：下載離線使用
1. 下載 `index.html`
2. 直接用瀏覽器開啟（Chrome、Safari、Firefox 皆可）
3. 無需網路，無需安裝任何軟體

### 方法三：分享給他人
將 `index.html` 傳給對方，對方用瀏覽器開啟即可。

## 技術說明

- 單一 HTML 檔案，約 7.4 MB（所有聖經資料內嵌其中）
- 純前端，無伺服器需求
- 支援 iOS Safari、Android Chrome、桌面瀏覽器
- 中文解析器支援繁體中文引用格式，含位置式數字（二一=21）
- 英文解析器支援縮寫、全名、逗號連續節、換章（N:M 格式）
